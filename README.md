# iPad Soundboard PWA

เวอร์ชันนี้แก้สำหรับ iPad โดยเฉพาะ

## สำคัญ
ห้ามเปิด `index.html` โดยตรงจากแอป Files หรือหน้าดูไฟล์ใน ChatGPT เพราะจะไม่ทำงานเหมือนเว็บไซต์จริง
ต้องนำโฟลเดอร์นี้ขึ้นเว็บแบบ HTTPS ก่อน แล้วเปิด URL ด้วย Safari

## วิธีลง GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่รากของ Repository
3. เปิด Settings > Pages
4. ที่ Build and deployment เลือก Deploy from a branch
5. เลือก Branch: main และ Folder: /(root)
6. กด Save และรอให้ GitHub แสดง URL
7. เปิด URL นั้นด้วย Safari บน iPad
8. กดปุ่มแชร์ > Add to Home Screen
9. เปิด Open as Web App แล้วกด Add

## วิธีใช้งาน

1. เปิดแอป แล้วแตะ “แตะเพื่อเริ่มใช้งาน” หนึ่งครั้ง
2. กด “เปิดโหมดแก้ไข”
3. กดรูปเฟืองใต้ปุ่มที่ต้องการ
4. เลือกรูปจาก Photos/Files
5. เลือกเสียงจาก Files
6. แตะรูปวงกลมเพื่อเล่นเสียง

## รูปแบบเสียงที่แนะนำบน iPad

- M4A / AAC
- MP3
- WAV

ควรใช้ไฟล์เสียงขนาดเล็ก เพื่อไม่ให้พื้นที่จัดเก็บของ Safari เต็ม
